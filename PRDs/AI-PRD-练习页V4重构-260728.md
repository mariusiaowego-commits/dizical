# Practice Page V4 Redesign Plan

**日期**: 2026-07-28  
**触发**: dad 5 点反馈 — 要素太多、用户复杂、需重构

## 问题诊断

| # | 问题 | 根因 |
|---|------|------|
| 1 | 编辑弹窗 form-input 无预设标签 | editSessionModal 只放了裸 input，没有 content_tags |
| 2 | BPM 不跟 assignment 默认值 | fillSessionDefaults 有查 assignments 但优先级被 session 覆盖 |
| 3 | 补录下拉菜单丑陋低效 | extra 用 `<select>` 而非跟主计时一样的 item-grid |
| 4 | 计时+补录上下堆叠，颜色相似 | 两个不同逻辑混在同一卡片，视觉区分弱 |
| 5 | 录入后无醒目展示 | session-panel 只是小号输入区，不是信息展示组件 |

## 设计方案

### 布局重构: 3 区 → 2 Tab + 1 Dashboard

```
┌─────────────────────────────────────────────┐
│  🎵 选择练习项目                              │
│  [search] [格子] [格子] [格子] ...            │
│  ─────────────────────────────────────────   │
│  📊 当前练习                                  │
│  ┌─────────┐  ┌─────────────────────────┐   │
│  │  🎯 萨丽哈 │  │ ♪=80  第1分句连吐  5min │   │
│  │   item   │  │  (表盘式信息展示)         │   │

│─────────────────────────────────────────────│

│  └─────────┘  └─────────────────────────┘   │
└─────────────────────────────────────────────┘
```

### 详细设计

#### 1. 编辑弹窗 content_tags

在 `editSessionModal` 的 emContent 上方加 content_tags 行，跟 sessionPanel 的 `sessionContentTags` 一样渲染预设标签。点击标签填充 input。

#### 2. BPM 自动跟随 assignments

当选择 item 后，`fillSessionDefaults` 已查 assignments（fallback）。问题是优先级：
- 当前: session 优先 → assignment fallback → 默认 80
- 修正: **assignment 优先**（老师要求），无 assignment 时 fallback 到 session，再 fallback 80

且赋值后 hint 显示来源：「♪=92 (老师要求)」

#### 3. 补录 item 选择器

替换 `<select>` 为 item-grid（跟主计时一样的按钮网格）：
- 点击科目按钮选中
- 已选中高亮（珊瑚红）
- 搜索过滤
- 效率跟主计时对齐

#### 4. Timer / Extra 分 Tab

两个 `<button>` tab 切换：
- **计时练习**（珊瑚红 #FF6B6B）— dial knob + wheel + content input
- **快速补录**（暖橙 #FF8C5A）— 简化版：item grid + minutes picker + content + submit
- 点击 tab 切换内容区，带动画过渡
- 颜色明确区分：红=计时，橙=补录

#### 5. Dashboard 展示组件

选完 item 并填写 BPM/content 后，在计时器旁渲染一个 "表盘卡片"：
- 左侧：科目名（大号）+ id
- 右侧：♪=BPM | content | 时长（醒目显示）
- 类似 Apple Watch 的 Modular 表盘布局
- 更新时机：选 item / 改 BPM / 填 content 时实时刷新
