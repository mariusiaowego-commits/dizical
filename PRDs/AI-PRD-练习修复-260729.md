## §3 修复策略

### §3.1 快速补录字段契约修复

- 前端：把 `session_detail` 合并到顶层三字段（`tempo_note/tempo_bpm/content`），不再嵌套
- 后端：仍接受 `session_detail` 嵌套作为 alias，validator 合并到顶层
- 路由 `has_session_detail = all(k in body for k in ("tempo_note", "tempo_bpm", "content"))` 不变

### §3.2 behavior_log 去重

- `save_practice_session_and_daily_summary` 内部 append 一次（事务内）
- 路由 `api_log` / `api_save_record` 仅在 `not has_session_detail` 时再 append（兼容旧前端发 behavior_log 的情况）

### §3.3 MySQL CRUD 对等

- 实现 `update_practice_session` / `delete_practice_session` 整事务版本
- 抽取 `BaseBackend` ABC 防今后再遗漏
- MySQL DDL 改 `BIGINT` 与 `schema_mysql.sql:128` 对齐

### §3.4 实战补完

- `submitPractice` / `addExtraMins` body 加 `practice_at: nowCstLocal()`
- `selectArchivedItem` 复用 `selectItem` 状态机
- `isToday` 用 CST 本地日期
- `renderTodayRecords` 改 `textContent` / `createElement` 拼

### §3.5 Pydantic 校验

- 新增 `src/kid_app/schemas.py`，`PracticeLogRequest` 校验
- 422 错误统一格式

### §3.6 5s 防重

- API 路由层加 `{item_id, minutes, second_window}` dedup 字典，TTL 5s
- 撞窗口返 409 或 200 with `dedup_message`

## §4 数据不变量

```
∀ date, ∀ item_id:
  daily.items[item].minutes == SUM(practice_sessions.duration_minutes WHERE practice_date=date AND item_id=item_id)
  # 历史数据 (无 session) 容忍 legacy_offset
  # 新数据必须满足 sessions_sum == daily.items[item].minutes

∀ POST /api/log with session_detail:
  behavior_log[].length after commit == 1
  practice_sessions.started_at == body.practice_at (CST ISO)
  practice_audit_log 增 1 条 channel=internal method=save_session

∀ PUT /api/practice-sessions/{id}:
  practice_items.last_tempo_note/bpm 同步更新
  daily.items[item_id].minutes += (new_duration - old_duration)  # clamp >= 0

∀ DELETE /api/practice-sessions/{id}:
  daily.items[item_id].minutes -= deleted.duration_minutes
  若归 0, 移除该 item 行
  total_minutes 同步更新
```

## §5 API 合同

### POST /api/log

请求（Pydantic 校验）：
```json
{
  "date": "YYYY-MM-DD",
  "item": "string",
  "item_id": "int",
  "minutes": "int>0",
  "is_extra": "bool",
  "log": "string?",
  "practice_at": "string?",
  "behavior_log": "[{enter_time,item,minutes}]?  deprecated",

  "tempo_note": "♪|♩|♬ ?",
  "tempo_bpm": "40-150 ?",
  "content": "string 1..200 ?",
  "content_source": "manual|legacy|backfill ?",

  "session_detail": "{tempo_note,tempo_bpm,content,content_source}?  alias"
}
```

响应：
```json
{ "ok": true, "total": 49, "session": { id, ... 11 fields } }
```
