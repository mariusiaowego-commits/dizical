# dizical macOS App

**状态**: 未启动 (优先级低, 微信小程序优先)

## 目标

macOS 菜单栏原生 app, 类似 [tw93/mole](https://github.com/tw93/mole), 点开快速访问 kid-app 5 个页面。

## 技术方案 (待定)

- A. Swift + SwiftUI 全重写 (3-6 月, 学习曲线陡)
- B. Swift + WKWebView 嵌 dizical (1-2 月, 学习 Swift)
- C. Tauri (Rust + WebView, 2-4 周, 学习 Rust)
- D. Python + rumps + WebView (1-2 周, 跟你 Python 栈一致)
- E. PWA (1-2 天, 零代码, 借 Safari)

## 优先级

**等微信小程序跑通后再开**。原因:
1. mac-app 跟小程序体验重叠 (都是 dizical 客户端)
2. 微信小程序用户量更大 (家人 + 朋友都可能用)
3. mac-app 主要给你自己用 (1 个人)
