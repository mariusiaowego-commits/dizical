卡面细节 A/B 对比 v1.5.0-dev 回 demo 版本表

① 「金环」在哪（把那一圈涂成洋红）

大白话：金环 = 卡片最外圈那一圈金属边框，整圈一样宽。 已按你的 l1 减细：11px → 6px，而且环数从 5 条收到 3 条（去掉两条同色系暗环）。 上下左右是同一圈，不是上边一条、下边一条。这一圈现在是： 0–1px 暗色掐丝（就是 l4 说的"底座"）→ 1–5px 主金 #d4a017 → 5–6px 内高光。 右边是把左上角放大 3 倍的样子，三条环可以逐条数；洋红宽度 = 现在的金环宽度（页面直接读 --ccg-rim-w，以后改宽度这里自动跟随）。

② 底座（最外 1px 暗色掐丝）去 / 留

两张卡只差最外面那 1px 一条暗线（#342205），金框的宽度、位置、其余 2 条环完全一样。 留 = 现在线上的样子（金框外面再包一条暗边，像掐丝珐琅的底托，卡面更"厚"、边界更硬）； 去 = 金框直接压到卡片最外缘，卡面更轻、更贴屏幕。

③ 防伪强度 ×1（现值）/ ×1.6 / ×2.4

同一根强度系数，同时加在两层上：常驻暗纹（不碰鼠标也隐约可见的底纹，现值 0.2） 和 聚光灯扫过时的彩虹镭射。把鼠标在卡上来回扫，看三张的差别。 现值偏弱，如果选 ×1.6 或 ×2.4，我就按这个档位接生产（见下方"接生产"说明）。

④ 淡色主题的金框（l2 拍板"固定"后）

你拍"固定"之后，薄荷玉 / 樱雪的边框已改回金色，不再跟着主题变绿 / 变粉。 这三套淡色主题的卡片底色、文字、镭射色调都没动。
