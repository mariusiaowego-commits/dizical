## §1 根因（已定，不要另找别的解释）
`--dash-ink`（#2C3E50）与 `--dash-muted`（#666666）在 `:root[data-skin="ink"]` 里**照抄浅银值没翻转**，
却被当**正文色**用 → 深底上成为深色字。实测（我跑的，浏览器全页扫描）：
```
深墨 .brand「D5 今日记录」  #2C3E50 on #2C3E50 → 对比度 1.00（完全看不见）
深墨 「展开」按钮           #666666 on #3E474E → 1.65
深墨 .c-detail session 明细 #2C3E50 on #1A1E34 → 1.53（dad 报的那条）
浅银 .v.delta.up「+27」     #FF6B6B on #FFFFFF → 2.78（< 3.0）
```
这两个 token **同时**还当填充色用（`background: var(--dash-ink)`、渐变色标、`.is-on` 反色钮、
`background: var(--dash-muted)` D3:516），**所以不能直接翻转它们**，要新增会翻转的语义文字 token。

## §2 任务 A — 新增 4 个会翻转的语义文字 token（6 个文件全体）
在 `:root` 与 `:root[data-skin="ink"]` 里各加：

--dash-delta-up:    #E04A4A;              /* 浅银 */   ink: #FF6B6B   /* 「多」红色文字用 */
--dash-delta-down:  #0C8A60;              /* 浅银 */   ink: #10B981   /* 「少」绿色文字用 */

`requests-popout-v1-v2.html` `today-records-01.html` `d5-design-probe.html`
（探针是 agy 的文件，你**只改 token 块与文字色**，别动他的结构与探针逻辑。）

### 替换规则（**按属性名逐条判断，禁止无脑全局替换**）
替换（这些都是文字色）：
- `color: var(--dash-ink)` → `color: var(--dash-text)`
- `color: var(--dash-muted)` → `color: var(--dash-text-soft)`
- 行内 `style="... color: var(--dash-muted)"` 同上
- JS 里写死的字符串 `'var(--dash-ink)'` / `'var(--dash-muted)'`（如 D3 的 `tip.style.color`）同上
- D4 的别名 `--c-secondary: var(--dash-ink)` → `var(--dash-text)`；`--c-muted: var(--dash-muted)` → `var(--dash-text-soft)`
- tap/on 反色钮：`.seg button.is-on` / `.fold button.is-on` 里 `background: var(--dash-ink)` → `var(--dash-text)`
  （浅银同值不变；深墨变成亮底 + `--dash-page` 深字，可读）
- 「多/少」的红绿**文字**：把用 `--dash-coral` / `--dash-mic-on` 当**文字色**的地方（如 `.v.delta.up/.down`、
  hero 里的 ±mm）改成 `--dash-delta-up` / `--dash-delta-down`

**保留不动**（这些是填充/线条，不是文字）：`background:` `border` `box-shadow` `linear-gradient` `fill` `stroke`
里的 `--dash-ink` / `--dash-muted` / `--dash-coral` / `--dash-mic-on`。
