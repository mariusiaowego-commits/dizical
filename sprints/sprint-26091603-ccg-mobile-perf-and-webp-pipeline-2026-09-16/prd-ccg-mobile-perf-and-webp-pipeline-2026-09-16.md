# PRD · CCG 移动端 3D 动效零卡顿治理与 WebP 缩略图分流管线 (Sprint 26091603)

## 1. 业务价值与用户诉求

- **用户场景**：女儿及 Dad 在 iPad mini、手机移动端使用 Safari 浏览器打开「成就殿堂」与「徽章图鉴」。
- **当前痛点**：
  - 打开页面需要下载 70MB+ 图片，弱网或首次打开需等待十几秒，甚至白块卡死；
  - 列表页面在 iPad 上滑动时出现掉帧顿挫，点击卡片打开 3D 详情时卡顿 200ms+；
  - 3D 卡牌触摸拖拽时严重拖手滞后，感觉“陷入泥潭”。
- **预期体验**：
  - 首次打开 1–2 秒内秒出卡片图鉴（总下发数据量由 70MB 压减至约 1.1MB）；
  - 列表像精致的高保真印刷卡片，滑动与浏览维持 60fps 丝滑满帧；
  - 点击卡片进入 3D Modal 把玩舞台时，瞬间弹出无顿挫；单卡 3D 旋转与高光粒子跟手无延迟（< 20ms）。

## 2. 功能与体验需求清单

| # | 功能项 | 详情描述 | 验收基线 |
|---|---|---|---|
| F1 | Modal 打开冻结背景墙 | 详情弹窗打开时，底层卡墙停止一切 3D tick、sheen 与动效，解除全屏高斯模糊与动态 3D 重绘并发冲突 | 弹窗弹出耗时从 200ms 降至 < 30ms，弹窗期间背景静止零重绘 |
| F2 | 列表态 SVG 滤镜剥离 | 列表态 `.ccg-stage[data-mode="wall"]` 不挂载 `#oracle-ink-bleed`，静态矢量墨迹兜底；仅聚焦单卡启用动态分形滤镜 | 彻底消除 WebKit Software Rasterization CPU 强制回退 |
| F3 | 触屏端列表去 Idle Drift | 移动触屏设备 (`pointer: coarse`) 列表态静止展示，禁止 18 张卡无脑自动晃动 | 列表常态 GPU 算力占用骤降 80% 以上 |
| F4 | 触摸即时跟手优化 | 缓存卡片 BoundingRect，缓动系数提速，触摸时直接跟手 | 触摸延迟从 500ms 降至 < 20ms |
| F5 | WebP 缩略图分流管线 | 44 张徽章图自动生成 320px 缩略图与 1024px 高清图，支持 WebP 透明通道；列表优先加载 320px 缩略图，Modal 异步加载高清原图 | 首屏图片总传输量从 70MB 降至 ~1.1MB，解码显存从 176MB 降至 ~18MB |
| F6 | 无缝 Fallback 机制 | 不支持 WebP 的旧浏览器自动回退到现有 PNG 原图 | 零破坏性变更，老旧客户端完全兼容 |

## 3. 非需求与边界约束
- **桌面端体验不劣化**：Mac 桌面端通过鼠标 hover 时仍保持细腻的高光交互；
- **盲盒体系不受波及**：盲盒卡片（`#card-daily-blindbox`）保持原有圆形与逻辑不受影响；
- **后端数据库不动**：不新增数据表或修改已有数据表结构。
