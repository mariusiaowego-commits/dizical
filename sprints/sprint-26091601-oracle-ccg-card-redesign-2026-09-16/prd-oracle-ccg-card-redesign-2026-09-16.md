# PRD · Oracle 典藏卡体系重构

## 1. 需求背景与目标

在 PR #326–#329 已上生产的 CCG 卡面基础上，dad 在真机端多轮验收后提出两个核心视觉问题，并要求「本地 Demo 先行、看满意后再投产」：

1. **粗重金框喧宾夺主**：卡面外框为 6px 粗重实心金色边框，视觉重量超过中央原画，卡片像被「相框框住」而非「一幅画」。
2. **名牌多边形生硬切割**：卡面左下角名牌使用 `clip-path: polygon()` 硬切割，斜切边在缩放时显得机械生硬，缺乏收藏卡的材质感。

同时 dad 要求在 Modal 内提供**沉浸式整卡把玩**体验，并移除原先突兀的关闭按钮。

### 核心目标

- 金框视觉重量降至「一条细金属线」，视觉重心回归中央原画
- 名牌改为自然材质边缘（矢量水墨泼墨），消除机械切割感
- 建立「一卡一色」的分类识别体系（7 系分类各有专属底板 + 印章）
- Modal 提供 3D 刚性整卡翻转 + 无按钮化极简交互

### 成功标准

dad 在真机（iPad mini Safari / Mac）目视验收通过，无「边框抢戏」或「名牌生硬」反馈；全量回归测试零失败。

## 2. 用户故事

| 角色 | 场景 | 期望 |
|------|------|------|
| 女儿（练习者） | 在成就页浏览卡墙 | 卡片像「珍藏卡」，中央插画是第一视觉焦点 |
| 女儿 | 点开某张卡把玩 | 卡片能翻转看卡背典故，交互沉浸、无多余按钮干扰 |
| 女儿 | 区分不同类型成就 | 通过底板色 + 印章一眼识别分类（突破/巅峰/晋级…） |
| dad（管理者） | 验收卡面质量 | 卡面达到「典藏卡」质感，无廉价感 |

## 3. 功能需求

### 3.1 细金掐丝边（替代粗金框）

- 外框视觉宽度从 6px 降至 1px（白）+ 1.5px（金属）双层描边
- 保留金属质感但不再抢占视觉重量
- 卡面面积视觉上增大，原画成为第一焦点

### 3.2 矢量水墨泼墨名牌

- 名牌底衬采用宣纸渗墨质感（噪声位移滤镜模拟墨迹边缘）
- 含飞白丝缕与自由迸散墨星，边缘自然不规则
- 逐张卡独立渲染，避免机械重复

### 3.3 7 系分类底板与专属印章

| 分类 | 底板氛围 | 印章 |
|------|----------|------|
| 突破 | 紫罗兰 → 深绿 | 专属金章 |
| 巅峰 | 深蓝 → 金 | 专属金章 |
| 执着 | 深蓝紫 | 专属金章 |
| 晋级 | 翠绿 | 专属金章 |
| 神秘 | 深紫黑 | 专属金章 |
| 段位 | 朱红 → 紫 | 专属金章 |
| 主题 | 琥珀金 | 专属金章 |

- 分类由 `artToneFromTag()` 对 badge `tag` 做白名单匹配，未命中回落「主题」
- 印章为内联 SVG 精铸金章，`aria-label` 供无障碍读取

### 3.4 沉浸式 3D 整卡翻转舞台

- Modal 内卡片支持整卡刚性 180° 翻转（正面 ↔ 卡背典故）
- 卡背为象牙白底 + 四角回纹装饰，完整展示典故内容
- 轻点（位移 < 6px）触发翻转，拖动触发倾斜
- **零关闭按钮**：仅「点击毛玻璃空白区域」或 ESC 退出

### 3.5 卡墙（列表态）

- 卡墙网格接入新卡面，locked 态走 CSS 灰化
- 卡墙卡片点击打开 Modal

## 4. 非功能需求

- **性能**：不引入新的运行时依赖；卡墙沿用既有 IntersectionObserver 视口护栏 + idle-skip 控帧机制
- **兼容**：适配 iPad mini Safari / Mac Safari / Chrome / mac app WKWebView
- **无障碍**：印章等装饰元素带 `aria-label`；Modal 有 `role="dialog"` + `aria-modal`
- **隔离**：仅改前端静态资源与模板，后端与数据库零改动

## 5. 非目标（明确不做）

- 不改后端 API 契约、不动 `achievements` 表结构
- 不新增 npm/pip 依赖
- 不重构 3D 几何参数基线
- 不实现「卡墙列表态零监听器静态化」（Demo 中的探索项，未纳入本 PR 生产范围）
