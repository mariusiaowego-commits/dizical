## D2-1 根因

dad 听的是 `metronome-01-v3.html`。开关只改了字和灯的标签。

`toggleAccent()` 把 `accentEnabled` 翻过来，按钮写成「强弱拍：开/关」。发声在 `scheduleHit()`：第 1 拍**不看这个开关**，一律当重音——音高和增益都更高（木鱼是 980Hz / 0.36，其余拍 720Hz / 0.22）。开关为真时只是再把峰值乘 1.3。所以关掉也一直听得见重音，打开只是略响一点，听不出差别。

v4 的引擎没有这条路径，`accentFlags` 仍是 0。dad 的口径还是不要重音。

收尾：v3 标成对照页，开关改成真开关，**默认关 = 四拍同一音高、同一增益**。打开之后第 1 拍才更高更响。这样默认状态符合「不要重音」，而开关终于听得见差别。

| | 改前（开关显示关） | 改后，关 | 改后，开 |
|---|---|---|---|
| 第 1 拍 / 第 2 拍频率 | 980 / 720 | 720 / 720 | 980 / 720 |
| 峰值 | 0.36 / 0.22，开着再 ×1.3 | 0.22 / 0.22 | 0.36 / 0.22 |
| 开关是否进引擎 | 否，只乘一层增益 | 是 | 是 |

`?audit=1`：`accentOff.sameAsBeat2: true`，打开后 980 对 720。`ASSERT_OK`。
