## 改什么

### A. 接法从「并排追加」改成「顶替 pk-main-col」
**现在（错）**：`.cz-row` 里 `pk-stage-wrap` + `czModCol` 并排 → 六卡挂在画布**右边外面**（实测模块 left 1283 / 1779… 视口 1265 之外，要横滑才见）。
**要改成**：模块列**装进 `pk-main-col` 内部**，顶替它原有内容：
- 移除 `pk-main-col` 里的：入卡槽说明行 / 计时大框 / `检票 · 开始练习` 按钮 / `老师要求` 板块
- 这些位置上装我们的模块（仪表盘 / 节拍器 / 竖条 / 今日时长 / 今日记录 / 老师要求卡）
- **保留不动**：顶部 banner、左栏 `pk-left-col` 票卡（380 宽）、画布自身的底色/字体/圆角语言
- 组合开关（4 预设 + 6 卡勾选 + 视口 + 皮肤）继续放画布**外面的细条**上
- 模块列内部**恒单行**；塞不下就在**模块列自己**里横滑（dad 口径：一屏展示、超宽右滑）
- 断言：模块列**不存在**于 `pk-main-col` 之外（实测模块祖先链必须命中 `pk-main-col`）；`pk-main-col` 内原有四个块实测不存在（按 DOM 查询结果断言，别只看肉眼）

### B. 在仪表盘（D1）上方加「插入卡槽」动画
画布原有语言是打卡机 → 票卡入槽（截图里那句 `打卡机入卡槽 · 点击下方「检票 · 开始练习」自动插入票卡` + `待命入槽` 药丸）。
要在**模块列最上方、仪表盘卡片之上**做这个动作：
- 形态：一条**卡槽**（横槽）＋一张**票卡缩略**从上方滑入槽内、落定后「点亮」下方仪表盘（仪表盘从待命态进入可用/运行态）
- 缓动：`back.out` 量级，全程 **≤320ms**，禁止弹跳过头、禁止 emoji、禁止旋转图标
- 触发：优先接画布原有的 `检票 · 开始练习` 语义（该按钮已移除 → 用我们自己的开始动作触发；若判不出来，就在槽位上加一个**极简**触发点，命名 `czInsert`）
- 待命态：槽是空的、票卡在上方悬停（静止，**不许自循环动画**）
- 实现：CSS + JS 或复用 `docs/demos/vendor/gsap.min.js`，**不新增依赖**
- 断言（可实测）：`idle` 时票卡与槽不相交、无动画在跑（两次采样 transform 一致）；触发后票卡与槽**相交**（几何判定，不是看类名）、仪表盘态变化、总时长实测值 ≤320ms + 缓动函数名
- 负控：把触发去掉/把动画改成 `infinite` → `idle` 那条必须报红，红行含两端原文（两次 transform 实测值）
