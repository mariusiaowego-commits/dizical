## 2 三条根因（实测挖出）

1. **计时中音符气泡不出**（D1.2 一半）—— 共享件 `setRunningModality()` 自己不吐气泡；生产靠计时循环每秒
   `paintRulerRunning + revealVine + pulseMarker + emitBubbles`（`practice.html:2858-2867`）。已写入契约 §5.2 并修好，实测通过。
2. **节拍器卡里长出刻度尺**（C.3）—— 不是 CSS 泄漏，是该卡整块抄了尺子 markup（699–705 行）。修法：共享件加**作用域根**
   `mount({root})`（负控实测：新容器 0→60 刻度、原尺子不受影响）+ 生成器改写 + 门禁守卫「引尺子必有尺子 markup」。
3. **「−」点一次内部跳到 30**（D1.3 附）—— `applyDuration` 把 `nextMin*60`（秒）传给单位是**分钟**的
   `RulerProduction.setDuration`。已修：传分钟；实测 `10分钟 → 9分钟`，滑杆 + 红针同步一格。
