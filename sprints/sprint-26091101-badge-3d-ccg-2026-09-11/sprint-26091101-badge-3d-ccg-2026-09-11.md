## 🔧 Followup (2026-09-12): dad 三连反馈修复 + Amazing Rare 版式

**触发**: dad 真机看 8 组截图后反馈「卡面太灰蒙蒙 / 没有光照感 / 没有镭射」。

**根因 (实测定位) → 修法 → 实测数据**

| 反馈 | 根因 | 修法 | 实测 |
|---|---|---|---|
| 太灰 | `--ccg-void: #cfd8e3` 浅灰底摊薄 chroma | 深空藏青 `#16224a` + 箔底 `#0e1a3e` | 卡面 mean chroma **42.2 → 75.3 (+78%)** |
| 无光照感 | `overlay` 混合深底不发光 + `farthest-corner` 盖满全卡无方向 | `screen` + 56% 椭圆定位指针 | 受光区 **138.6 → 237.4 (+71%)**；对角远端 192.3→195.9 不变 |
| 无镭射 | 缺光谱 + spec 用 soft-light | 12 段太阳柱 `--ccg-sunpillar` + spec 改 `screen` + 镜面 glare | hover spec 1.0 / glare 1.0 / laser 0.54 |

**版式 (Amazing Rare 结构)**
- 上 2/3: `.ccg-art-frame` 立体倒角金框 + `.ccg-art-window` 凹槽内嵌 (箔层与聚光灯裁在框内, 指针坐标换算到框内局部系)
- 下 1/3: `.ccg-info-bar` 两端收尖银条 (NO./分类/日期) + `.ccg-plate` 米色说明栏 (名字/星级/条件) + `.ccg-foot` (成就殿堂/DIZICAL)
- 清理死选择器 `.ccg-meta` / `.ccg-kicker` / `.ccg-sub` / `.ccg-layer-text`；JS 统一 `cardMarkup(scheme, d)` 入口
- 静止态聚光灯 `IDLE_Y=14` / `IDLE_LIT=0.22`：停在上金边/画面上沿，不下压图案正中 (dad 2026-09-12)
