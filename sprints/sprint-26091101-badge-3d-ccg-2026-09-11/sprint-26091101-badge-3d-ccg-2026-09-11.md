# 🚀 Sprint 26091101 - 徽章集卡化 3D CCG 改造 (双方案并重 + 全局领取拦截)

## 📋 需求背景与痛点
1. **女儿无获得感**：练笛时新徽章默默解锁，女儿无感知，无仪式感。
2. **展示偏静态**：徽章缺乏可玩度与收集欲，需要 3D 镭射全息卡牌（CCG 风格），支持 iPad 触屏拖拽把玩、光影游走。
3. **dad 明确要求**：方案一（pokemon-cards-css）与 方案二（holo-card-studio 理念）两套都要做，都要看效果，可能都会保留，投入同样精力。

## 🎯 验收标准 (DoD)
- [x] 数据库迁移：`achievement_stats` 增加 `claimed_at` 字段，老数据迁移安全，加部分索引，`practice_audit_log` 加 `detail` 列。
- [x] 后端 API：`GET /api/badge/unclaimed` 与 `POST /api/badge/claim` 跑通，幂等无异常，审计日志记录。
- [x] 方案一（纯 CSS 全息光影卡牌）完整实现：七彩虹光箔、镜面光斑跟随、3D 角度变换、Spring 回正。
- [x] 方案二（纯 CSS 3D 分层视差深度卡牌）完整实现：背景、原画主体、全息金边、文字 Z 轴真实悬浮分层、翻转卡背。
- [x] 独立把玩对比页 `/static/badge-ccg-demo.html` 可在 iPad/Mac 上流畅互动（≥60fps，触控防穿透）。
- [x] 全局拦截弹窗组件接入 `_sidebar.html`：检测未领徽章强弹窗，横屏 744px 左右双栏适配。
- [x] 领取入库粒子礼花动效（GSAP 金色粒子雨，卡牌飞入成就殿堂）。
- [x] 自动化测试 `tests/test_badge_claim.py` 100% PASS (10/10)。
- [x] 全页面冒烟测试通过，Chrome headless 截取 8 组高清 Retina 验资截图。
