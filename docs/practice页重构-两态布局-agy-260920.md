## 3. 练习态仪表盘“要素清单”与层级排列

为实现 dad 要求的“要素丰富、排列统一和谐”，仪表盘内部建立严格的**空间槽位与视觉权重**：

```
+-------------------------------------------------------------------+
| [槽位1: 身份栏 36px]   吸气长音  ·  ♩ = 80  ·  长音练习 (13px 弱化) |
|-------------------------------------------------------------------|
| [槽位2: 核心时间 90px]            03:12                           |
|                         (72px 等宽大字, #2C3E50)                   |
|                        [ 总计 10 分钟 · 剩余 06:48 ]               |
|-------------------------------------------------------------------|
| [槽位3: 进度总线 80px]                                            |
|   |--|--|--|--|--▶-----------------------------------| (480px)   |
|   (红针平滑位移 + 底轨卷草纹生长 + 音符气泡冒出, 步进键 disabled)  |
|-------------------------------------------------------------------|
| [槽位4: 控制总线 54px]                                            |
|                  [ 暂停 ]           [提前结束]                     |
|              (180×44px 次级键)     (次级幽灵键)                    |
+-------------------------------------------------------------------+
```

### 3.1 视觉层级定义 (60cm 持笛阅读)
1. **绝对主导 (Weight 1)**：`03:12` 读数（72px SFMono，居中不位移）。
2. **动态指示 (Weight 2)**：480px 刻度尺红针进度 + 卷草纹生长。
3. **上下文认知 (Weight 3)**：顶沿身份栏（科目名加粗 14px，速度与标签 13px 弱化浅灰），证明计时归属，只读不可改。
4. **行动控制 (Weight 4)**：底部控制按键，弱化避让，不干扰孩子吹笛视线。

### 3.2 运行态 (Running) vs 暂停态 (Paused) 状态迁移表

| 要素 | 运行态 (Running) | 暂停态 (Paused) | 不变量守则 |
|---|---|---|---|
| **大字读数** | 正常流逝计数（72px, `#2C3E50`） | 停留在当前秒，**微弱呼吸渐变闪烁** | **坐标、字号绝对 0 位移** |
| **状态胶囊** | `[ 总计 10 分钟 · 剩余 06:48 ]` | 文案变为 `[ 练习已暂停 ]` | 容器尺寸与锚点不变 |
| **刻度尺真件** | 红针平滑步进，气泡动态冒出 | 红针停在当前刻度，气泡动效暂停 | 尺子轨道物理位置不变 |
| **主 CTA** | 文案为 `[ 暂停 ]`（次级黄底 `#F0D060`） | 切换为 `[ 继续练习 ]`（珊瑚红 `#FF6B6B`）| 尺寸固定为 180×44px |
| **次级按键** | 右侧 12px 伴随轻量 `[提前结束]` | 保持 `[提前结束]` 可点击 | 不产生位置突跳 |

## 4. 关键专项问题解答

### 4.1 老师要求卡在练习态：全文展示、同宽同列与极限 175 字方案
- **同宽同列定案**：
  - 准备态宽 `670px`，练习态宽 `720px`，始终与上方的仪表卡**在像素级严格同宽**，并保持垂直紧贴（gap 16px）。
- **高度定稿**：
  - 练习态高度释放至 **280px**。
  - 排版规格：标题 14px 加粗，正文 `16px`（重点小拍子/音符参数加粗 17px），行高 `1.65`，段落间距 `8px`。280px 高度可完美平铺 7-8 行结构化段落，覆写 95% 以上常规周作业，字大清晰。
- **极限 175 字超长应对**：
  - 超过 8 行时，卡片内部固定前 7 行，底沿保留 1 行高度施加平滑渐隐遮罩（Fade Mask），并浮现右下角胶囊 `[查看全文 ↗]`。
  - 点按后直接拉起全屏毛玻璃阅读层（字号 18-20px），阅读层关闭后毫秒级归位。**计时核心 Worker 与刻度走字完全在后台平稳推进，绝不停表**。

### 4.2 「今日练习记录」在两态的摆放与折叠策略
1. **准备态（决策期）**：
   - 放置于**顶部导航条右侧**，作为状态指示胶囊：`[今日记录: 15分/3次 ▾]`，**默认常态折叠**。
   - 点击后从屏幕右缘滑出 `320px` 侧边抽屉（Drawer），查看今日练习明细与家长编辑项，不占用主画幅。
2. **练习态（吹奏期）**：
   - **完全隐去展开入口，仅在顶栏保留单行文本**（`今日累计: 18m`）。
   - **理由**：孩子双手持笛专注吹奏时，过往的历史流水卡片不仅无用，反而是严重的情绪干扰与视觉杂音。练习态必须保持极致纯粹的“仪表+作业”双卡闭环。
