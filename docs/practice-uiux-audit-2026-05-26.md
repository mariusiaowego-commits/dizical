# Practice 页面 UI/UX 排查报告

> 日期：2026-05-26
> 分支：`feat/practice-ui-ux`
> 文件：`src/kid_app/templates/practice.html`

---

## 🚨 高优先级：交互逻辑与防呆设计 (UX)

### 1. "未选择科目"时的状态处理太粗暴
- **现状**：未选科目直接点"开始"或"提前结束"，弹系统原生 `alert('请先选择一个科目')`
- **建议**：原生 alert 非常打断体验。应在未选择科目时，直接将"开始"和"提前结束"按钮置为 `disabled` 状态（视觉灰化，降低透明度），从根源上阻止误触。选中科目后再高亮激活。
- **✅ 已修复**

### 2. "提前结束"按钮暴露时机不对
- **现状**：计时器还没开始跑的时候，"提前结束"按钮就大剌剌地摆在那里
- **建议**：只有当 `timerRunning === true` 或 `elapsed > 0` 时，才显示或激活"提前结束"按钮。
- **✅ 已修复**

### 3. "快速录入"缺少触发入口
- **现状**：代码里写了 `#quickAddSection` 和 `toggleQuickAdd()` 函数，但在当前 UI 界面上没有任何按钮可以触发打开这个面板，成了一个死胡同
- **建议**：在计时器面板或者科目选择区附近，加一个类似"⚡ 补录练习"的次级文本按钮。
- **✅ 已修复**

---

## 🎨 中优先级：视觉语义与一致性 (UI)

### 1. 主操作按钮的"类名"与"视觉语义"倒置
- **现状**："开始"用的是 `.btn-secondary` (绿色)，"提前结束"用的是 `.btn-primary` (红色)
- **建议**：Primary 应该是当前页面的核心正向操作（开始），Danger/Destructive 才是破坏性操作（提前结束）。"开始"改为 Primary 样式（绿色渐变），"提前结束"改为 Danger 样式（纯红），并把类名语义理顺。
- **✅ 已修复**

### 2. 科目按钮的"彩虹色"缺乏逻辑
- **现状**：科目网格用了 `:nth-child(5n+x)` 分配 5 种不同颜色，视觉上像打翻的调色盘，且没有任何信息分类价值
- **建议**：统一用一种品牌色（或带透明度的渐变），通过选中态来强调即可。
- **✅ 已修复**：统一为 `linear-gradient(135deg, #6BCB77, #4ECDC4)` 品牌渐变

### 3. "删除"按钮样式割裂
- **现状**：今日练习记录列表里的删除是 32px 大红圈，右侧"额外练习时间"里的删除是 24px 小红圈
- **建议**：统一组件库。删除这种危险操作，建议统一采用"图标按钮+Hover变红"或统一尺寸。
- **✅ 已修复**：统一为 28px 透明灰图标，hover 变红

### 4. 时间选择按钮的排版拥挤
- **现状**：`5分钟 10分钟 15分钟...` 几个按钮在 iPad 竖屏或稍小的屏幕上挤在一起
- **建议**：改为 Segmented Control（分段控制器）样式，把它们连成一个整体，更省空间且视觉更紧凑。
- **✅ 已修复**

## 📱 低优先级：响应式与微交互

### 1. 缺少 Hover 状态反馈
- **现状**：大量使用 `:active { transform: scale(0.96) }`，适合触屏。但鼠标操作完全没有 Hover 状态。
- **建议**：给所有可点击元素加上 `:hover { filter: brightness(1.05); }` 或轻微上浮阴影。
- **✅ 已修复**

### 2. 三栏布局的 Grid 比例过于"精确"
- **现状**：`grid-template-columns: 0.656fr 1.316fr 1.014fr;` 小数点后三位的比例难维护，不同 DPI 下可能产生亚像素渲染模糊
- **建议**：简化为 `2fr 3fr 2fr`，视觉差异几乎为零，代码清爽得多。
- **✅ 已修复**

### 3. "额外练习时间"面板的定位模糊
- **现状**：和"快速录入"在功能上有点重合，放在最右侧容易被忽略
- **建议**：考虑把"额外练习"和"快速录入"整合成一个"手动记账"的折叠面板，放在计时器下方，而不是拆在两边。
- **⚠️ 未修复**（需进一步讨论整合方案）
