「提前结束练习」弹窗 · 布局重设计

原型取自 dad 反馈的「上轻下重」：遍数滚轮整块挤在下半区、六处留白偏大。
改法：切成 3 个有边界的区（卡头 / 练习时长 / 练习遍数），遍数区内部 压成一行（标签 + 滚轮 + 档位同排），靠分区边界与背景色差重新分配视觉重量。 滚轮视觉本体与交互语义原样复用，未改。

滚轮可操作：▲ 增加 / ▼ 减少 · 点上下相邻数字 · 拖动滚轴 · 点右侧档位 · 键盘 ↑ 增加 ↓ 减少 0-9 直设
