  }

ui.setOptions(rawOrArray); // 不发 onChange，不清空

ui.getValue();
ui.open();
ui.close();
ui.destroy();
  • 点「＋」列出全部标签，不按输入框里已有的字过滤。接着打字，就按输入框实时过滤。
  • Enter 选中当前高亮行。面板关着时，Enter 把输入框里的文字当成自填提交。
  • Esc、点栏外，关上面板，不改已提交的值。末尾 × 清空，并 onChange('', { source: 'clear' })。
  • 面板是栏的兄弟，position: absolute; bottom: calc(100% + 8px)，不占高度。票卡这一截不要 overflow: hidden，否则向上的面板会被裁掉。
  • 根 .pss：is-empty is-selected is-open is-custom is-fallback。
