老师要求 · 常用音乐符号面板（可点）

三档宽度并排：375（手机）/ 440（iPhone 竖屏）/ 744（iPad mini 竖屏）。每个框右上角有「符号」按钮，聚焦输入框也会自动跟随弹出。

怎么试
  1. 点任意「老师要求」输入框 → 面板跟随该框出现；点右上角「符号」按钮也能开。
  2. 点面板里的符号 → 插入到光标处（不是复制到剪贴板，所以不用长按黏贴）。
  3. 看 375 档：先点「+ 添加科目要求」才会有第一个框；没加之前面板不会乱弹。
  4. 「速度」框（如 ♩=82）也能用面板；点面板时输入框不会失焦，光标位置保留。
  5. 不遮挡原则：面板永远不盖住正在输入的框 —— 下方空间够就贴在下方，不够就翻到上方，两边都不够时面板自己限高内滚，绝不上移盖住输入框。底部有实时判定读数（「遮挡输入框：否」＋间距 px）与滚动跟随。
  6. 底部「最近插入的字段内容」实时显示插入结果，用来核对插入位置正确。
