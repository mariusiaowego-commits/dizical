## 2 两处根因（都是我实测挖出来的，不是猜的）

**① 计时中音符气泡不出（D1 条目 2 的另一半）**
- 实测：计时真在走（`08:37 → 08:34 · 练习中`），22 个气泡槽 `animationName: bubbleUp` 但 `opacity` 恒 0；花开有 15 朵。
- 根因（查生产 `practice.html:2858-2867`）：`setRunningModality()` **自己不吐气泡**，只写 `#metaVal` + hint；生产靠**计时循环每秒**驱动
  `paintRulerRunning(p)` + `revealVine(p)` + `pulseMarker()` + `emitBubbles()`。D1 v3 缺这个循环（`grep emitBubbles` = 0 处）。
- 处置：已写进 `card-contract.md` §5.2「运行态动画完整配方」（逐字对齐生产），并派 agy 返工 + 加页内断言。

**② 节拍器卡里长出刻度尺（compose 条目 3）**
- 实测/查证：不是 CSS 泄漏，是 `metronome-01-v2.html` **整块抄了生产尺子 markup**（699-705 行）+ 引了共享件，却没打算放尺子。
- 处置（我的架构件）：
  - 共享件加**作用域根**：`mount({ root: 元素 })`，内部 DOM 查询统一走 `q/qAll/byId`；实测新容器 0→60 刻度、原尺子不受影响。
  - 生成器（`tools/gen-ruler-shared.py`）负责改写 + 自检（改写 13 处 / 残留 0 / rootEl 已声明），**不手改产物**。
  - 门禁加守卫：**引了共享尺子却没有尺子 markup ⇒ NG**（`scripts/verify-demos.py`）。
  - v3 里 metronome 已彻底不引。
