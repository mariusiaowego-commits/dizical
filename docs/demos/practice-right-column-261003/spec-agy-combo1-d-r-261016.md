## 1. 现象根因与 Dad 批评定性（Item 6.2 & 6.3）

1. **D 今日时长卡“元素过少、空白过多”的根因**：
   在组合 1 下半部，D 卡横向宽度被收窄至 $224\text{px}$。先前的改动误以为“窄卡就要删元素”，粗暴地剥离了空心大时钟、虚实时间轴刻度胶囊和包豪斯双图标，只留下一串干瘪的文字数字，导致 224×243px 的卡片内部大面积死白空虚。
2. **R 今日记录卡“脏灰底”与风格分裂的根因**：
   实测 R 迷你卡计算样式为 `background: rgb(232, 229, 224)`（#E7E5DF 灰）。这原本是浅色外壳的底色，直接涂在卡面上显得像个未加载完成的线框占位符；而左侧的 D 卡却拥有精致的包豪斯深炭黑表盘，二者并排并列时视觉极其撕裂。

## 2. D 今日时长卡：224 宽 vs 360 宽元素响应式映射表

D 卡必须保持其核心身份：**包豪斯极简时间仪表（Bauhaus Duration Widget）**。在任何宽度下，其标志性的四大视觉支柱均不可剥夺：
1. **日期标注行（Date Row）**
2. **空心单线大时钟（Monoline Clock）**
3. **时长总结胶囊（Duration Pill）**
4. **虚实交错时间轴胶囊（Timeline Rail Capsule）**

### 两档宽度元素呈现对比矩阵：

| 模块要素 | 360 宽档（组合 2 / 组合 3 / 宽屏） | 224 宽档（组合 1 下半卧排左卡） | 224 宽紧凑适配处理手法 |
|---|---|---|---|
| **顶部日期** | `Tuesday 17`（字号 14px） | `Tue 17` 或 `10-15 周二`（字号 12px） | 保持顶栏存在，不留空隙 |
| **空心大时钟** | SVG Monoline 162×52，字号 48px，带右上角秒数 | SVG Monoline 缩放至宽 130px，字号 32px，隐藏小秒数 | **坚决保留空心大时钟！** 居中呈现精工质感 |
| **总结胶囊行** | `Practice` 标签 + `2H 45M` 珊瑚红胶囊 | 保持单行：`练` 徽标 + `2h 45m` 紧凑胶囊 | 消除多余 margin，紧凑贴合 |
| **时间轴刻度胶囊** | 全宽轨道（宽 320px），标注 4 组时间刻度（07:15 / 07:45 / 08:15 / 08:45） | 紧凑轨道（宽 180px），仅标注首尾 2 组刻度（如 `07:15` 与 `08:45`） | **坚决保留虚线基线与实线白段！** 完美展现练习片段 |
| **右下双图标** | 萨丽哈笛管微缩线描 + 包豪斯几何装饰印章 | 仅保留微型笛管线描徽标（16×16px） | 保持角落微细节，拒绝死白 |

> **关键原则**：224 宽不是“残废版”，而是“高密度精致微型版”！四大要素完整在场，彻底消灭空白死洞。

## 4. 可量判据（Price-Tag Verification Criteria）

在实际运行与自动化巡检中，必须通过以下价签：

1. **R 卡灰底彻底绝迹**：
   实测 R 卡外框及其内部主面板的计算背景色：
   $$\text{computedBackground}(\text{cardR}) \ne \text{'rgb(232, 229, 224)'} \quad \&\& \quad \ne \text{'#E7E5DF'}$$
   其主面板背景色色值亮度通道（Luminance）必须 $\le 0.15$（即严格处于深炭黑区间 `#101418` $\sim$ `#181D22`）。
2. **D 卡 224 宽四要素完备性检测**：
   在组合 1 下，探测 D 卡内部 DOM 节点：
   - 空心时钟 SVG 存在且可见：`clockSvg.offsetWidth > 80px`
   - 时间轴轨道存在且可见：`railTrack.offsetWidth > 120px`
   - 实线白段数量 $\ge 1$
   - 虚线基线 SVG 存在
3. **D 与 R 视觉同心同高闭合**：
   在组合 1 下：
   $$|h(D) - h(R)| \le 1.0\text{px}$$
   $$|t(D) - t(R)| \le 1.0\text{px}$$
   $$|b(D) - b(R)| \le 1.0\text{px}$$
   $$w(D) + \text{gap}(12) + w(R) = 460\text{px} \equiv w(A)$$
