## 1. 卡槽拟物嵌入仪表盘顶边规格（Item 8 解决）

### 1.1 现状缺陷诊断
实测现状中，`.pk-punch-slot-wrap.cz-punch-slot` 是一个独立存在于仪表盘上方的外置条块：
- 坐标尺寸：`width: 460px; height: 48px; left: 394px; top: 21px; bottom: 69px`
- 仪表盘 A 顶边位于 `top: 76px`，两者之间存在 **7px 明显的空白断层（seam）**
- 条块上被塞入了三行破坏拟物真实感的大段说明文字（*“打卡机入卡槽 · 点击下方「检票·开始练习」自动插入票卡 / 待命入槽 / 吸气长音”*），像一个突兀的网页横幅，而不是硬件打卡机/音响设备的入卡口。

### 1.2 拟物卡槽工程定义：开在仪表盘顶壳上的内凹槽
卡槽必须**取消独立外挂条**，改为在仪表盘 A 卡本体的外壳金属/塑胶顶边上**向下切削出的物理凹槽（Integrated Top Slot）**。

```
┌────────────────────────────────────────────────────────┐  ← 仪表盘 A 卡整体顶边 (Top Edge)
│       ┌────────────────────────────────────────┐       │
│       │  ▼▼▼   DARK INSET SLOT (内凹卡槽)  ▼▼▼  │       │  ← 凹陷深度 16px ~ 20px
│       └────────────────────────────────────────┘       │
│                                                        │
│  [Grille 6x8]         [Readout 00:00]        [BPM 82]  │  ← 仪表主面板
│                                                        │
```

#### 关键几何与视觉参数
1. **槽宽与相对位置**：
   - 槽宽比仪表盘外框略收窄（左右各留出 $24\text{px}$ 壳体边界）：
     - 组合 1（仪表盘宽 460px）时：**槽宽 $W_{\text{slot}} = 412\text{px}$**，居中对齐；
     - 组合 2/3（仪表盘宽 430px）时：**槽宽 $W_{\text{slot}} = 382\text{px}$**，居中对齐；
   - 槽外壳宽度与票卡（360px）的关系：票卡能够恰好对准并“插入”此凹槽区间。
2. **深度与嵌入量**：
   - **外部突出高度**：$0\text{px}$（与仪表盘顶缝隙 seam 彻底归零，严禁外浮在卡外）；
   - **向内凹陷深度**：$16\text{px} \sim 20\text{px}$；
   - **内陷拟物质感（CSS 拟物规范）**：
     ```css
     .dash-integrated-slot {
       position: relative;
       margin: 0 auto;
       width: calc(100% - 48px);
       height: 18px;
       background: #11141a; /* 极深金属槽腔底色 */
       border-radius: 4px 4px 6px 6px;
       box-shadow: 
         inset 0 3px 6px rgba(0, 0, 0, 0.8), /* 槽内深部阴影 */
         inset 0 1px 2px rgba(0, 0, 0, 0.9),
         0 1px 0 rgba(255, 255, 255, 0.15);  /* 下边缘微弱高光倒角 */
       border: 1px solid rgba(0, 0, 0, 0.6);
       border-top: none; /* 顶边直接与卡片边缘融通 */
       z-index: 10;
     }
     ```
3. **层叠与层级关系（Z-Index & Stacking）**：
   - 仪表盘顶壳 `.dash-top-rim`：`z-index: 10`
   - 入卡凹槽内衬 `.dash-slot-cavity`：`z-index: 9`
   - 票卡插入动画轨迹：当插入动画发生时，票卡下半截自槽口深入，被槽腔前端覆层遮挡（`clip-path` 或前景挡板），形成真实的“入机”感。
4. **清理破坏质感的说明文案**：
   - **完全删除**原条块内的所有冗余文字（“打卡机入卡槽 / 点击下方检票...”）；
   - 仅保留极简的极小字号激光镭雕蚀刻风格提示（或仅保留一个小向下三角徽标 `▾ INSERT TICKET ▾`，字号 `10px`，颜色 `rgba(255,255,255,0.25)`，字母间距 `2px`），强化工业拟物感。

## 2. 组合 1 内部重排与格子图规范（Item 12 解决）

### 2.1 组合 1 整体布局格子图（1133 宽屏基准）
组合 1 属于一屏紧凑型布局，总高度与左栏票卡严格等高（$H = 780\text{px}$）。
总横向结构为两列：
- **第 1 列（中轴复合列，宽 460px）**：由“上半 A 仪表盘”与“下半并排卧式 D+R”纵向堆叠而成；
- **第 2 列（节拍器列，宽 130px）**：全高单列竖条节拍器 S。

### 2.2 各卡内部元素针对性重排细节

#### (1) A 仪表盘（460px × 440px 紧凑盒）重排方案
当仪表盘置于组合 1 的上半矮盒（高 440px）时，禁止按 780px 全高展开，必须执行以下元素收敛：
- **保留核心**：
  - 孔阵 `.grille-6x8`：保持 $72\text{px} \times 72\text{px}$；
  - 空心计时大数字 `#ttCounter`：保持 `48px` 字体高亮；
  - 核心读数与波形联动。
- **收拢与精简**：
  - **底部诊断白卡 `.diag-card`**：取消独立白色背景框（消除 73px 的纵向占用），改为高度仅 $24\text{px}$ 的紧凑透明状态行，与底边并齐；
  - **`.toast-banner`**：取消静态常显占位（原占位 21px），设为默认隐藏（`opacity: 0; pointer-events: none;`），仅当鼠标 hover 状态图标或点击触控时悬浮弹出；
  - **BPM 读数与微调区**：由纵向散落改为单行紧凑排列于主屏右下角（如 `BPM [ - ] 82 [ + ]` 单行高 36px）。
- **结果**：内容总高度控制在 $410\text{px} \le 440\text{px}$，卡内绝对不产生纵向滚动条。

#### (2) D 今日练习时长小卡（224px × 328px 卧左）重排方案
原时长卡为宽卡设计，挤进 224px 窄卡后必须转换为纵向紧凑卡片语言：
- **顶部标题（高 36px）**：
  - 图标（秒表 18px）+「今日时长」（14px 粗体黑字）；
- **主读数区（高 120px，垂直居中）**：
  - 巨大数字：如「**45**」（字号 `40px`，`font-weight: 800`，字偶间距紧凑）；
  - 单位标注：「分钟 / 今日」（`13px` 灰色附标）；
- **进度与目标区（高 70px）**：
  - 横向圆角药丸进度条（高 8px，填充珊瑚红渐变 `#FF6B6B`）；
  - 进度文字：「达成 75% · 目标 60 分钟」（`12px` 浅灰）；
- **收敛规则**：彻底去除宽版中的多余装饰性说明段落。

#### (3) R 今日练习记录小卡（224px × 328px 卧右）重排方案
Dad 原话明确指出：今日练习记录**不要在小卡片里塞列表**！
- **顶部标题（高 36px）**：
  - 图标（书本/音符 18px）+「练习记录」（14px 粗体黑字）；
- **打卡摘要（高 120px，垂直居中）**：
  - 巨大完成数：「**3**」（字号 `40px`，`color: #2b8a3e` 森林绿）；
  - 副标题：「项练习已完成 · 0项待练」（`13px`）；
  - 状态标记：精致绿色对勾徽章（Enamel Badge 质感）；
- **下部交互呼出按钮（高 56px）**：
  - 醒目拟物操作胶囊按钮：`[ 查看记录明细 ↗ ]`；
  - 样式：浅珊瑚底色边框，点击高亮；
  - **点击行为**：**触发全局 Popout 弹窗**，在浮层中展现完整练习科目列表（绝不在 224px 卡内展开模糊层！）。

## 3. 可量判据（Price-Tag Verification Criteria）

1. **卡槽与仪表盘无缝嵌入**：
   - 槽底边与仪表盘顶边的垂直间隙：
     $$\text{seam} = t(\text{dash}) - b(\text{slot}) \le 0\text{px} \quad (\text{实测必须嵌进或相交 } 0 \sim 2\text{px})$$
   - 槽宽度约束：
     $$W_{\text{slot}} = W_{\text{dash}} - 48\text{px} \pm 2\text{px}$$
2. **组合 1 下半卧排几何闭合**：
   - 下半两张卡宽度并排：
     $$w(D) + \text{gap}(12) + w(R) = 224 + 12 + 224 = 460\text{px} \equiv w(A)$$
   - 下半两张卡顶边与底边绝对对齐：
     $$t(D) = t(R) = t(A) + 440 + 12 = t(A) + 452\text{px}$$
     $$b(D) = b(R) = b(\text{ticket})$$
3. **滚动条 0 容忍**：
   - 组合 1 中 A、D、R、S 四张卡片本体内部：
     $$\text{scrollHeight} \le \text{clientHeight} \quad (\text{四张卡均无纵向或横向滚动条})$$
