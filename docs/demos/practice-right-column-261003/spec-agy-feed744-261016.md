## 1. 核心设计原则：内容驱动高度（Content-Driven Heights）

### 1.1 现状缺陷根因
实测现场中，在 744 视口（iPad 竖屏）下，六张卡片（A 仪表盘、B 节拍器、S 竖条、D 时长、R 记录、Q 老师要求）无论内容多寡，**被脚本全部一刀切强制指定为 `708px × 460px`**：
- **今日练习时长卡 D**：横向铺满 708px 后，内容仅需约 240px，却被拉伸出 460px，下方留出大量难看的死白大窟窿（Dad 第 7.2 条）；
- **今日练习记录卡 R**：限定 460px 高度，导致记录较多时卡内强行出现原生纵向滚动条，破坏 Feed 流整体阅读体验（Dad 第 7.3 条）；
- **S 节拍器**：原本是窄竖条，硬塞成 708×460 后严重畸变（Dad 第 7.4、7.5 条）；
- **Q 老师要求卡**：宽度规则未继承满宽，且高度死板，文字截断（Dad 第 7.6 条）。

### 1.2 无限下滑 Feed 档铁律（Dad 原话指示）
> *“既然是无限下滑 feed 流了，那么高度就做好适配让内容展示完整就结束，不要限制高度，不要出现右侧滚动条。”*

**两大核心铁律**：
1. **彻底废除 `height: 460px` 硬编码**：
   在 ≤744 视口下，所有卡片容器必须使用 `height: auto; min-height: fit-content;`，高度完全由卡片内真实内容自然撑开。
2. **彻底消灭卡内原生滚动条**：
   卡片内部禁止声明 `overflow-y: scroll` 或 `overflow-y: auto`。卡片必须一次性将所有条目、刻度、图形完整展现，由页面主视口（外层 Feed 轨道）统一负责平滑向下滚动。

在 744px 视口下，舞台宽度 744px，卡片统一宽度为 **$W = 708\text{px}$**（左右留 18px 边距，居中对齐）。各卡自适应目标排布如下：

## 3. 440 档（卡宽 416px）单列自适应规则

在 440px 视口（iPhone 竖屏）下，卡片宽度统一为 **$W = 416\text{px}$**（左右留 12px 边距，`box-sizing: border-box`）：
1. **排布方向**：严格单列流式，上下 `gap: 16px`；
2. **各卡高度计算**：
   - **A 仪表盘**：单列垂直居中，高约 **$340\text{px} \sim 360\text{px}$**；
   - **S 节拍器**：横条形态（字号与按纽略收拢），高约 **$96\text{px}$**；
   - **D 今日时长**：大时钟与时间轴垂直居中排布，高约 **$220\text{px}$**；
   - **R 今日记录**：表格转为移动端卡片列表项（每项高约 56px），全量展示无滚动条，高度 $h = 56 + N \times 56\text{px}$；
   - **Q 老师要求**：任务卡片气泡流，高约 **$160\text{px} \sim 200\text{px}$**。

## 4. 可量判据（Price-Tag Verification Criteria）

在 744 与 440 视口下运行自动化测试，必须满足以下硬性物理价签：

1. **全卡 0 内滚铁律**：
   在 744 档与 440 档，遍历右栏所有可见卡片 $C_k \in \{A, B, S, D, R, Q\}$：
   $$\text{clientHeight}(C_k) == \text{scrollHeight}(C_k) \quad (\text{溢出量 } \equiv 0\text{px})$$
   $$\text{getComputedStyle}(C_k).\text{overflowY} \ne \text{'scroll'} \quad \&\& \quad \ne \text{'auto'}$$
2. **脱离 460px 诅咒判定**：
   对 744 档所有可见卡片，其高度必须呈现**内容异构性**：
   $$\{h(A), h(S), h(D), h(R)\} \text{ 不得全部相同}$$
   $$h(S) \le 120\text{px} \quad (\text{横条必须生效})$$
   $$h(D) \le 280\text{px} \quad (\text{时长卡不得留出死白窟窿})$$
3. **记录卡 R 与记录条数 $N$ 严格单调相关**：
   $$h(R_{N=3}) < h(R_{N=6})$$
   记录增多时卡片自然向下延展，页面外层高度相应增加，卡内无折叠滚动。
4. **单列垂直零重叠**：
   对相邻卡片 $C_i$ 与 $C_{i+1}$：
   $$\text{top}(C_{i+1}) \ge \text{bottom}(C_i) + 16\text{px}$$
