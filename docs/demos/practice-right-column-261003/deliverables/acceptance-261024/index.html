01怎么看这份包

先在浏览器里逐张对照截图，再打开本地 demo 亲手动效（插卡、票夹变形、节拍器拖拽与长按）。截图只能证结构与排版，动效手感必须真机看。

动手入口： 运行 python3 -m http.server 8771 --bind 127.0.0.1 --directory docs/demos， 打开 http://127.0.0.1:8771/practice-right-column-261003/canvas-01.html（当前已起，PID 见 lsof -nP -iTCP:8771）。
顶栏可切视口（1133 / 744 / 440）、组合（1 / 2 / 3）、皮肤（浅银 / 深墨）；主画布右上「切到练习态」进计时态。
本轮另修一处：组合 2 的「今日练习记录」小卡，右上角数字标签原来显示 未选内容 次（把收拢态“本次练习内容”当成次数拼进去）。 已改为读今日记录胶囊：现在显示 3 次，主数字 15 分 也改读同一来源。
