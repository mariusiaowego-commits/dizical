## 一、三个 HIGH（不改不能看）

**① D1 机身被拉扁** — 原来 `width: var(--vp-w)` 把机身拉到 1109×678（1.64 宽），完全不像仪器。
→ 改 `width: min(100%, 420px)`，高度填满所在列并封顶 660px。实测 420×511（0.82 近正方形），`dashOverflow 0,0`。

**② D1 换肤是死的** — `:root[data-skin="ink"]` 整段被包在注释里，顶栏「深墨」按下去没反应。
→ 解除注释 + 新增「浅银 / 深墨」切换器。实测 `--dash-panel` 从 `#1C1E21` → `#14181C`。

**③ D4 手势打架** — 长正文滑动被卡片 3D 拖拽吞掉，滑文字直接把卡划飞（agy 实测复现）。
→ 正文加 `touch-action: pan-y`，拖拽处理里 `e.target.closest('.card-body-content')` 直接放行。
实测正文 `touch-action: pan-y` 生效，顶层卡 420px，无溢出。

## 二、两条误触/假证据（工程性错误）

**④ D3「开始」与「提前结束」实测只隔 5px** → 拟物键间隙 6 → 12px，扁平胶囊 4 → 8px，两钮不再连成一颗。440 视口另加收紧规则。

**⑤ D2 自检面板假证据**（grok 独家找出）— 969 行 `cumulativeDriftMs` 直接写 0，对外断言「恒等于 0」「< 0.1ms」，而同一段日志里实测最大偏差是 0.4535ms。
→ 改为按末拍实测位置算真实累积偏移；判定阈值由实测值算（PASS/FAIL 动态出）；加一行说明探针搜索窗 20 样本 = 量化上限 0.4535ms（偏差未超此值即等于零误差）。所有数字均为运行输出，无写死项。

## 四、工艺（better-ui 逐条）

- **同心圆角**：D1 深色屏 28 → 22（外壳 36 − 内边距 14）；封面外框 16 → 15；D2 自检终端 8 → 4（面板 16 − 内边距 12）。
- **`transition: all` 归零**：D3 2 处、D4 6 处、D2 2 处 —— 全部改成列具体属性（`all` 会连布局属性一起动，产生隐形抖动）。
- **过冲缓动收紧**：D4 弹窗原来进出共用 `cubic-bezier(...1.56...)`，关闭时会先撑大再缩 → 退场改无过冲曲线（0.22s），入场保留轻微弹性（1.56 → 1.28）；卡片回位 `back.out(1.5)` → `power3.out`；D1 扬声孔振幅 0.55 → 0.9。
- **动效不再一进页面就播**：D1 的 48 个扬声孔、D3 的 48 格栅孔原来加载即跳动 → gate 到「计时中 / 麦克风开启」，准备态静止；D3 另加「节拍示意：开/关」手动开关，关闭时孔位复位。
- **状态不只靠颜色**：D4 通知点脉冲降频降幅（1.8s/1.3 → 2.2s/1.18）；D3 麦克风指示灯 demo 态改虚线空心环（色盲/灰度下也能区分）。
- **文字字形换矢量**：D2 主启停 `▶ / ⏸`、D3 键帽图标、D4 关闭钮 `✕` 全部换 SVG。
- **封面外圈细线**：`rgba(255,255,255,0.55)` → 纯白 10%，深底上不再像亮框（四文件同步，契约一致）。

## 六、换肤契约（十三项新增 token）

v2 新增「透明度阶梯」13 项，四文件同一份定义，解决混色字面量（原来 `linear-gradient(180deg, #FF8282, var(--dash-coral))` 这种混写行旧的审查规则抓不到）。

```
浅银（:root）
  --dash-ink-a04/a12/a16/a25/a42    蓝灰透明度阶梯（投影、描边、蒙层）
  --dash-coral-glow / --dash-coral-a25
  --dash-accent-soft / -wash / -line / -glow
  --dash-gold-a35 / --dash-gold-glow
深墨（:root[data-skin="ink"]）只覆盖 ink-a04/a12/a16/a25/a42 ——
  深底上蓝灰透明看不见，翻向暖白；品牌色 alpha 沿用浅银值。
```

**审查规则（v2 起脚本化）**
1. 非中性色禁止字面量（蓝灰 / coral / accent / gold 及各自 alpha）。
2. 中性黑/白 alpha 允许保留 —— `rgba(0,0,0,α)`、`rgba(255,255,255,α)` 属投影与高光层级，不是颜色身份。
3. 禁止 `transition: all`。
4. 深墨皮肤不得被注释。

实测：四文件非中性色字面量 **0**、`transition: all` **0**、`:root[data-skin="ink"]` 全部活体、花括号平衡、内联 JS 过 `node --check`、引用 token 全部有定义、`--dash-*` 名集合四文件一致（62 个）。
