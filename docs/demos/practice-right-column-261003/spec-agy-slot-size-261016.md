## 1. 现状缺陷诊断：18px 狭缝吞噬动效（Item 2）

### 1.1 实测数据与 Dad 批评
现场实测 `#pkPunchSlotWrap`（`.dash-slot-cavity`）尺寸与坐标：
- 坐标尺寸：`width: 382px; height: 18px; left: 404px; top: 58px;`
- **致命缺陷**：槽深仅 **$18\text{px}$**！
  - 当用户在左栏点击「检票·开始练习」触发票卡插入动画时，票卡（宽 360px、高 500px+）向右滑入卡槽；
  - 但由于卡槽开口高度仅 18px，且容器设置了 `overflow: hidden`，票卡一滑进槽口**立即被截断吞没**；
  - 票卡上的打卡时间戳、条形码齿口、金色检票图章（Stamp）动效完全无法展现，用户只看到一个窄黑细线，毫无“打卡机吞卡印章”的物理仪式感。
- **Dad 原话**：
  > *“打卡机入卡槽的卡槽设计的高度不够导致里面动画效果都看不全，这个卡槽可以设计到 dashboard（仪表盘）里面去。”*

## 2. 拟物卡槽尺寸与内嵌结构重构

卡槽必须由“18px 扁窄狭缝”扩容为**深度充足、三层夹心的机载插卡仓（Integrated Ticket Bay）**，直接开凿在仪表盘顶部金属外壳之内。

```
┌────────────────────────────────────────────────────────┐ 仪表盘 A 外框
│                                                        │
│   ┌────────────────────────────────────────────────┐   │
│   │ [Top Bezel 高光金属导轨]                       │   │
│   │ ┌────────────────────────────────────────────┐ │   │
│   │ │  ▼▼▼   TICKET ENTRY CHUTE (深凹槽仓)  ▼▼▼   │ │   │ ← 槽口深度 48px ~ 52px
│   │ │                                            │ │   │   (完整展示卡头、印章、齿口)
│   │ │  [ 票卡插入停留态: 见图章与条形码 ]        │ │   │
│   │ └────────────────────────────────────────────┘ │   │
│   │ [Front Lip 前挡唇片 + 激光镭雕入卡指示线]     │   │
│   └────────────────────────────────────────────────┘   │
│                                                        │
│   ┌────────────────────────────────────────────────┐   │
│   │  #panel 黑色主屏显示区 (在卡槽下方 10px 处自然顺延)│   │
│   └────────────────────────────────────────────────┘   │
```

### 2.1 槽体核心几何尺寸
1. **槽口宽度（$W_{\text{slot}}$）**：
   - 票卡实际宽度为 $360\text{px}$；
   - 槽口左右各留 $12\text{px}$ 物理插卡裕量：
     $$W_{\text{slot}} = 360 + 24 = 384\text{px}$$
     （在 460px 仪表盘中，左右外壳各留 38px 边框；在 430px 仪表盘中，左右外壳各留 23px 边框，居中对齐）。
2. **槽口高度与深度（$H_{\text{slot}}$）**：
   - **由 18px 彻底扩展至 $48\text{px} \sim 52\text{px}$**；
   - 深度提升近 3 倍，确保能容纳并完整展示票卡上部 $40\text{px}$ 的核心动画内容。
3. **圆角与内陷拟物质感**：
   ```css
   .dash-integrated-slot {
     position: relative;
     margin: 10px auto 8px auto;
     width: 384px;
     height: 50px; /* 关键：充足高度！ */
     background: #0D1013; /* 深邃机仓底色 */
     border-radius: 8px 8px 12px 12px;
     box-shadow:
       inset 0 4px 8px rgba(0, 0, 0, 0.85), /* 顶部深槽阴影 */
       inset 0 -1px 2px rgba(255, 255, 255, 0.1), /* 底部卡位高光 */
       0 2px 4px rgba(0, 0, 0, 0.4);
     border: 1px solid rgba(0, 0, 0, 0.7);
     overflow: hidden; /* 卡身下半段自然隐入机器内部 */
   }
   ```

## 3. 三层层叠（Z-Index）与入槽动画舞台空间

为了达成逼真的打卡机吞卡效果，卡槽内部采用三层夹心渲染：

| 层级 | DOM 结构 | Z-Index | 职责与视觉表现 |
|---|---|---|---|
| **底衬层 (Cavity Back)** | `.slot-cavity-back` | `z-index: 1` | 槽腔内部后壁、深黑金属质感导轨线 |
| **票卡运动层 (Ticket Stage)** | `.slot-ticket-proxy` | `z-index: 2` | 动画映射票卡，沿 Y 轴自上而下滑入，并在指定位置（Y 偏移约 28px）悬停 |
| **前挡板唇片 (Front Lip)** | `.slot-front-lip` | `z-index: 3` | 卡槽下沿前凸挡板（带高光倒角），在视觉上遮挡票卡最下端，形成“插进缝隙”的真实纵深感 |

### 动画视觉可视窗口要求：
- **滑入行程**：票卡入槽时，动画沿纵向滑入位移 $\Delta Y = 36\text{px}$；
- **印章动效呈现**：在悬停就绪后，金色「已检票」图章自 1.4 倍缩放至 1.0 倍压盖在卡头上，图章尺寸 $32\text{px} \times 32\text{px}$，在 $50\text{px}$ 高度的卡槽窗口内完全可见，严禁出现任何切边截断！

## 4. 可量判据（Price-Tag Verification Criteria）

在实际运行与自动化巡检中，卡槽必须达到以下硬性指标：

1. **卡槽高度达标**：
   实测 `#pkPunchSlotWrap` 及其内部 `.dash-slot-cavity` 的高度：
   $$48\text{px} \le h(\text{slot}) \le 54\text{px} \quad (\text{严禁低于 } 40\text{px} \text{ 或等于 } 18\text{px})$$
2. **物理归属在仪表盘内部**：
   卡槽顶边与底边完全包含在仪表盘 A 卡框内：
   $$t(\text{slot}) > t(\text{dash}) + 4\text{px}$$
   $$b(\text{slot}) < t(\text{panel}) \quad (\text{位于主屏上方，与主屏间距 } 8\text{px} \sim 14\text{px})$$
3. **入槽动画无截断**：
   在检票打卡动画执行期间，入卡代理卡头的可见渲染高度：
   $$\text{visibleHeight}(\text{ticketHead}) \ge 36\text{px}$$
   金色印章图标完整渲染，无 CSS 截断（`overflow-clip` 区域不碰伤印章外边缘）。
