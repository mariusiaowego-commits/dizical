## 要做什么
组合1（上仪表盘整行 + 下两张并排）在**窄槽**（页顶宽度开关 460 / 620）时，下面两张卡各自宽度不够 → 显示不全。
改为：**放不下就降级成一行一张**（下面两张卡各占整行，纵向堆叠）。

判定标准（自己实现 + 自测，不许写死断点魔法数，要用实测能不能放下决定）：
- 下排每张卡有自己声明的最小宽度（卡契约 min 宽）——两张并排需要 `2 × minW + gap ≤ 容器宽`
- 够 → 并排；不够 → 一行一张
- 实现建议：CSS `@container`（容器查询）或 JS 实测 `scrollWidth` 判定后加 class；两者都行，但要**可复测**

## 硬要求
1. 组合1 在 **820 / 620 / 460** 三档都要**无横向滚动、无卡片被裁切**（`scrollWidth ≤ clientWidth + 1`，卡内元素不出框）。
2. 并排可行时**必须仍并排**（不能一律堆叠）：给出 820 档并排、460 档堆叠的实测证据；620 档按实测结果如实报（并排能放下就并排）。
3. 与既有「上宽 = 下两张合计」的断言兼容：并排时上宽 == 下两张 + gap；堆叠时上宽 == 每张宽（说明口径）。
4. 自检 `?audit=1` 必须 `ASSERT_OK`，并把「窄槽降级」写进自检断言，**打实测值**（各档：容器宽 / 两张卡 min 宽之和 / 实际布局行数 / 是否有横滑）。
5. 给**负控**：把降级判定关掉（强制并排）时应在 460 档报红，红行要出现两端原文（容器宽 vs 需要宽）。
