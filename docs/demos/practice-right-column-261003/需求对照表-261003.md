## 优化与创新（超出需求书的部分）

1. **换肤做成可校验的契约**：13 项「透明度阶梯」token 把混色全收口，四文件 `--dash-*` 名集合一致由脚本卡住 —— 呼应 1.0「可替换仪表盘样式」的诉求，且换皮只改一份映射。
2. **审查规则脚本化**：`verify-v2b.py` 七项（非中性色字面量 0 / `transition:all` 0 / ink 皮肤活体 / 花括号平衡 / 内联 JS 过 `node --check` / 引用 token 全有定义 / 契约一致）；改法脚本逐条断言、不匹配整体失败不写盘 —— 避免「半改」。
3. **节拍器零依赖零漂移 + 离线自检**：`OfflineAudioContext` 60s 采样级校验；v2 把写死的「累积漂移 0」改成实测输出 + 标出探针 20 样本的量化上限（原为假证据）。
4. **麦克风双链路降级**：有权限走真实拾音，无权限/拒绝自动降级到 82 BPM 演示包络，不抛错、不空转（D3）。
5. **占位显式化**：mock 值都带 `data-placeholder` + title，不让假数据冒充真实数据（D1 今日累计）。
6. **非颜色单通道状态**（可访问性）：麦克风 demo 态改虚线空心环、暂停补静态字、`prefers-reduced-motion` 关滚动 —— 不止靠颜色/动效表达状态。
7. **触控与误触**：44px 触控下限（±、预设芯片、关闭钮）、两钮间距 12px 防误触「提前结束」、`touch-action: pan-y` 把正文滚动从 3D 拖拽里救出来。
