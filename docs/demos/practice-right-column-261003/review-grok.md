# 观察轮 · grok（只审）

取证：Chrome headless + CDP `Emulation.setDeviceMetricsOverride`，视口精确为 1133×744、744×1133、440×956。尺寸来自 `getBoundingClientRect`。状态用页面上的按钮或全局函数走完。动效没有逐帧放到 10% 去看，读的是 `document.getAnimations()` 的 duration，加上样式里的 easing。参考图文件 4096×4096。没有改任何仓库文件。

三档页面 `scrollWidth-clientWidth` 与 `scrollHeight-clientHeight`：D1/D2/D3/D4 都是 0, 0。溢出不是这轮的主问题，裁切和误导才是。

## 1. 结论摘要

- D1 `dashboard-skin-01.html`：HIGH。1133×744 时机身 1109×678（宽高比 1.64），深色屏 1077×427，封面只有 92×92。参考图是接近正方形的一台仪器，这里被拉成一条宽网页。
- D2 `metronome-01.html`：HIGH。精度自检把累积漂移写成 0，并把「< 0.1ms」写死在文案里；同一次输出里的采样偏差是 0.4535ms。
- D3 `dashboard-bottom-blocks-01.html`：HIGH。准备态下「开始」与「提前结束」实测间距 5px（变体 B 为 4px）。误触会结束练习。
- D4 `requests-popout-v1.html`：HIGH。440×956 时卡片宽 420px，弹窗宽 414px，卡片超出弹窗。变体 B 有卡的右缘到 x=1210。

## 7. agy 三份里先修的 5 条

1. D2 自检结论是写死的 PASS（`metronome-01.html:969`）。dad 会拿它决定节拍器路线，假证据比丑更危险。
