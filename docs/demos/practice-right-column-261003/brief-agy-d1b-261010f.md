## 2.1.2 readout 计时开始后不该有「分钟」
dad 原话：> `readout-line` 计时开始后，后面的分钟就不对了（数字变成 mm:ss 时加「分钟」单位不对），计时开始后就直接不需要分钟这个单位了

**根因已定位（我查到的，直接用）**：模式属性的实值是 `data-mode="run"` / `"pause"`（见 CSS 现有 `.dash[data-mode="run"] #btnPrimary`），
而我们上一版写的隐藏规则是 `.dash[data-mode="running"] .readout-unit` → **选择器永远不匹配**，所以计时开始后小字还挂着。
修：改用真实值（`run` / `pause` 隐藏），并且**断言必须在 `run` 态真跑一遍**（切到计时中，实测 `.readout-unit` 不可见 / 数字为 MM:SS 时无单位），别再只测准备态。

dad 原话：> `grille-6x8 variant-countersink` 默认没有音浪没有声音的波动形成的波浪期间 默认阶段不应该里面有动画效果，我需要的是这里就是要展示自下而上的随着声音的强弱的孔阵的动画效果变化，就像声音的波纹一样。另外，列不够对，多加几列要和 `cover-frame` 一样宽度

要求：
1. **准备态（无音浪）必须完全静止** —— 默认阶段不许有任何动画在跑（断言：prep 态下孔阵无 running 动画 / 无 inline transform 变化，两次采样值相同）

5. 尽量沿用既有实现（`.grille-6x8.variant-countersink` 现成类名与 SVG/CSS 结构），不新增依赖
