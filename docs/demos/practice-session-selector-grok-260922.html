本次练什么

这是给练习票卡用的独立组件 demo。舞台宽 390px，等于票卡列的实际列宽；组件铺在票面内容区里（列宽减去边框和左右 18px 内边距，约 352px）。打开选择时票面高度应保持不变。老师要求不在这里，仍放名师指引卡。

形态

收起时只是票根上的一行字：衬线小标「本次练什么」，下面是选中的那一句。没有边框，也不摆输入框。点这一行，菜单从这一行的下沿以浮层打开，盖住下面的票根和检票按钮，不把票卡撑高。

标签每条占满一行，最少 44px，不换行。配了标签就用那一组；一条都没有，就用生产页同一套兜底：长音练习、吐音练习、连吐练习、换气练习。自己写一句收在菜单底部，写完才进入票面。

集成契约

把 PracticeSessionSelector 整段拷进票卡脚本。菜单节点会被挂到 document.body，因为 .pk-ticket 有 overflow: hidden，留在票卡里的浮层会被裁掉。不要把 body 做成 transform 或 filter 容器。

const ui = PracticeSessionSelector.mount(host, {
  options: PracticeSessionSelector.parse(item.content_options),
  value: '',
  onChange: function (value, meta) {
    // value: string（空字符串表示还没选）
    // meta.source: 'option' | 'custom'
    // meta.fallback: 这科没有 content_options 时为 true
    // meta.optionCount: 当前列表条数
  }
});

ui.setOptions(rawOrArray); // 不发 onChange，也不清空已选
ui.setValue('');           // 切科目时由票卡清空。不发 onChange
ui.getValue();
ui.close();
ui.destroy();
  • 根节点 .pss。状态类：is-empty is-selected is-open is-custom is-fallback。
  • 触发器 .pss-trigger，小标 .pss-kicker，句子 .pss-value（未选时再加 is-placeholder），自填标记 .pss-meta，箭头 .pss-chevron。
  • 菜单 .pss-menu（data-side="below|above"，打开时加 is-open），说明 .pss-note，列表 .pss-list，选项 .pss-option（当前项 is-current）。
  • 自填：.pss-custom .pss-custom-btn .pss-custom-form .pss-custom-input .pss-custom-ok。输入上限 200，与现在的练习内容输入一致。
  • 切科目沿用生产行为：setOptions 之后再 setValue('')。内容是否够格按「开始」，由票卡决定，这个组件不代管。
  • Esc、点菜单外、再点触发器，都会关上。上下键在标签之间移动。
  • 打开 180ms、关上 120ms，缓动 cubic-bezier(0.16, 1, 0.3, 1)，从下沿 translateY(-6px) scale(0.96) 收到原位。没有遮罩，也不做高度动画。prefers-reduced-motion 时取消位移。
