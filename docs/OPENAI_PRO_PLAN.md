Currently I use GPT-4o for AI-generated monthly practice report images — the system selects a template based on the student's practice data, generates a chart description, and produces a shareable image. The results go directly into the kid's iPad interface.

With more API credits I would:

**Expand the instrument range.** The current data model (lessons, practice items, stage progression, achievement badges) is not dizi-specific — it's a generic music practice tracker. Pro credits would let me build the same pipeline for piano, violin, or any other instrument my daughter picks up: the same practice heatmap, the same badge system, the same AI-generated monthly report, just with instrument-specific templates.

**Improve report quality.** Currently I generate one image per month. With more credits I could do weekly summaries, growth narrative summaries written from the practice data, and adaptive encouragement that adjusts tone based on whether the student is in a slump or on a streak.

**Experiment with multi-modal feedback.** Attach a recording of a practice session and get back a structured assessment — not a full AI tutor, but a quick sanity check: "the tempo on measure 4 is inconsistent, focus on the breathing transition in measure 7." This would require more API calls per session, which is why expanded credits matter.

The core workflow stays the same: data → prompt → image. More credits means more instruments, more frequency, more experiment.
