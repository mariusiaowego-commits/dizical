# dizical

Practice tracking for Chinese bamboo flute. Lesson scheduling, fee reminders, daily check-in, stage assignments, achievement badges, practice heatmaps, AI monthly reports.

iPad interface for the kid (prepare/practice/achievements/report). CLI + web panel for the parent. Apple Reminders sync — type "单吐10分钟" in Reminders, it logs.

Built for one family. Home server. No subscription. No cloud. MIT license.
