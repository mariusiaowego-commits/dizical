## 1. 视觉参考解码与模式提炼（借用与避坑）

### 1.1 历史截图诊断：`clip_20260922_133140_6.png`
- **画面内容**：
  展示了 v1/v2 中左侧"选科目"区域的一个局部科目卡片项（`吸气长音` / `本周作业` / `增加 高音6，2-4指 都可以。` / `♩=60`），四周带有明显的淡红色圆角线框，上方露出分类胶囊，下方露出下一个灰色线框。
- **反模式诊断（必须坚决摒弃）**：
  这是典型的**"边框套边框"**低级工程件。外层已经是一个卡片容器，内层每一个科目项又包了一个带完整独立边框的方形卡，视觉层级杂乱、线条拥挤、缺乏整体高级感。
- **可偷取的正向信息**：
  保留单项内部紧凑的键值配对结构（科目名靠左、重点作业胶囊靠右；老师要求摘要靠左、速度基准靠右）。在 v3 中，这一组信息不再作为被框住的小卡片，而是作为顶部快速选项卡与参数网格的直接数据源。

### 1.4 Inspora 三篇参考解码
- **`product-comps`（仪表类数字排布）**：
  - **主副读数层级**：72px 时间大数字作为绝对视觉重心，其余参数（BPM、节拍时值）全部降级为 18–20px 等宽数值，并搭配 11px 大写/加粗小标签，避免数字争抢注意力。
  - **遥测网格（Telemetry Bus）**：曲目、时速、练习 session 不散落在各处，而是整合进仪表盘上方的遥测面板内，水平对齐、分组明确。

  - 子级内容绝不突兀弹出，而是通过空间关联平滑滑出。在 v3 的「速度段抽屉」和「老师要求展开」中，完全继承这种沿主边框延伸的投影抽屉设计。
- **`interactive-cards`（卡片微交互）**：
  - 卡片交互强调机械质感（90ms 弹簧按压、入槽微阻尼回弹、非活动卡片半透明锁定），赋予数字工具以实体文具/乐器的手感。

### 3.2 三设备排法适配方案

1. **iPad 横屏（1133×744 主力规格）**：
   - 双栏并排：左侧统一长卡 **380px** + 右侧中轴 **660px**（仪表盘 340px + 名师指引卡自适应），间距 16px，总宽 1056px 水平居中。
   - 纵向严格控制在 744px 安全视口内，常规要求下一屏完整闭环无需翻页。
2. **iPad 竖屏（744×1133）**：
   - 响应式单列纵向流，主宽度锁定 **680px** 居中；左长卡在上，仪表盘居中，名师指引在下；纵向自然顺畅滑动。
3. **iPhone 窄屏（440×956）**：
   - 单列流体布局，左右边距收至 12px；长卡 Hero 区域高度压缩至 110px；音符时值与 BPM 步进器在保持 ≥44px 触控标准的前提下紧凑贴合。

## 5. 打卡机式卡片插入展示动画（分镜表与参数规范）

### 5.1 进入练习态动画分镜（从点击「开始练习」到吹奏态就位）

```
时间线 (ms):
0ms ──────── 120ms ──────── 240ms ──────── 320ms ──────── 420ms ──────── 600ms
[点击开始]
    ├──────── 左长卡暗化变淡 (opacity: 0.35, scale: 0.985) + 蒙版淡入 ────────┤
                ├────── 微缩卡头物理滑入插槽 (y: -24px → 0px, back.out) ─────┤
                                ├──── 仪表核心参数总线隐现点亮 (y: 8px → 0px) ───┤
                                            ├────── 计时启动、红针与气泡冒泡 ──────┤
```

| 步骤 | 参与元素 | 动效参数（位移 / 缩放 / 透明度） | 时长 / 缓动 | 终态与体验目标 |
|---|---|---|---|---|
| **Phase 1<br>母卡锁定** | 左侧长卡 `#pkSubjectCard`<br>锁定蒙版 `#pkCardLockOverlay` | `opacity: 1.0 → 0.35`<br>`scale: 1.0 → 0.985`<br>蒙版 `opacity: 0 → 1.0` | 240ms<br>`power2.out` | **双态锁定，骨架不跳**：左卡退居半透明后台，提示本卡已被装载锁定；整体两栏布局完全不跳动，拒绝整页白屏重刷。 |
| **Phase 2<br>机械插卡** | 仪表卡顶部微缩卡头 `#pkInsertedHead` | `y: -24px → 0px`<br>`opacity: 0 → 1.0`<br>`scale: 0.96 → 1.0` | 320ms<br>`back.out(1.5)` | **打卡机入槽隐喻**：像老式打卡机将工卡插进槽口，带轻微机械物理弹性，卡头露出拱形徽标与曲目名，外露 60px。 |
| **Phase 3<br>参数隐现** | 核心参数总线 `#pkRunTelemetry` | `y: 8px → 0px`<br>`opacity: 0 → 1.0` | 240ms<br>`power2.out`<br>(延时 100ms) | **芯片读取感**：打卡卡片入槽后，仪表盘核心参数（曲目/速度/session 胶囊）即刻在第一焦点位置优雅显现点亮。 |
| **Phase 4<br>进度接力** | 刻度尺红针、卷草纹、数字滚轮 | `ttOnStart()` 调用<br>红针走动 / 气泡冒泡 | 持续 | 时间数字平稳递增，刻度尺 ±1 步进锁定，进入沉浸练习态。 |

### 5.2 退出练习态反向动效（点击「提前结束」或计时完成）
1. 微缩卡头向上抽回弹离插槽：`y: 0 → -20px`, `opacity: 1 → 0`, 时长 180ms (`power2.in`)。
2. 左侧长卡锁定蒙版淡出，卡体恢复全亮：`opacity: 0.35 → 1.0`, `scale: 0.985 → 1.0`, 时长 240ms (`power2.out`)。
3. 刻度尺调用 `ttOnExit()`，卷草纹自右向左收卷，红针复位。
4. 底部弹出非阻塞轻量 toast 药丸：`已提前结束 · 卡片已归位`。

### 5.3 减弱动态降级（`prefers-reduced-motion: reduce`）
- 自动检测并跳过位移（`y`）与弹性缩放（`scale`）：直接锁定目标位置，仅执行 100ms 纯透明度淡入淡出，完全满足辅助功能无障碍要求。
