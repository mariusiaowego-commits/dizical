# practice 页两态布局草案（Hermes 版）

> dad 2026-09-20 新方向（原话要点）：
> 1. **要求卡与仪表卡同宽**，布局上**关联在仪表卡下方** —— 开始练习后可以边计时边看这个科目本周的老师要求
> 2. 整个练习界面分**两种状态**：**准备态**（选科目 / 定速度 / 选 session / 用刻度尺选时长）与**练习态**（点开始 → 围绕一个完整的**中央仪表盘**展示与交互）。两态**模块排列完全不同**，各自给出明确操作 flow
> 3. 练习态：刻度尺变成计时器（花朵生成动画、刻度移动、时间动效**保留**）；BPM、已选 session 等成为「进行中的仪表卡」的组成部分，让仪表盘要素丰富、排列统一和谐；下方关联展示该科目的老师要求（字体清晰、排版结构化）；练习态还要安排「今日练习记录」板块

---

## 0. 两态的定义与不变量

| | 准备态 Prep | 练习态 Running |
|---|---|---|
| 触发 | 进入页面 / 上一次结束 | 点「开始练习」后 |
| 用户要决定 | 练什么科目、什么速度（BPM）、练什么 session、练多久 | 不再做选择，只做控制：暂停 / 继续 / 提前结束 / 练习完提交 |
| 中央件 | 刻度尺 + 读数 = **选时长**（同一套真件，红针指所选时长） | 刻度尺 + 读数 = **计时进度器**（红针走完、花朵/卷草纹生长、时间动效、气泡） |
| 参数区（速度 / session） | 可编辑，摆在"决定"的位置 | **只读**，成为仪表盘组成部分 |
| 老师要求卡 | 与仪表卡同宽，在仪表卡**下方**（先读再开始） | 同位置保留（边练边看），字大、结构化 |
| 今日练习记录 | 折叠条（位置见 §2） | 见 §3 |

**共享的不变量**
- 刻度尺真件语义不变：1-30 分钟、每分钟 2 格、拖拽 + ±1、红针替换当前格
- 读数在选择态与练习态**字号一致、不许位移**
- 打卡链路契约不变（`/api/log`、`practice_at` CST、必填语义）
- 练习态的所有元素都在**一屏之内**（1133×744 横屏，不滚动）

## 1. 准备态布局草案（1133×744，左 rail 64px）

目标：一屏闭环「选科目 → 定速度 → 选 session → 拉时长 → 开始」。

```
┌ 顶部条 44px ─────────────────────────────────────────────────────────────────┐
│ 练习打卡          今日已练 15 分钟 · 3 次                        [今日记录 ▾] │
└──────────────────────────────────────────────────────────────────────────────┘
┌ 左列 420px ──────────────────┐ ┌ 右列 601px（= 仪表卡宽度）─────────────────┐
│ 1 选科目                     │ │ 2 中央仪表卡（准备态）                     │
│  [全部(10)] [本周重点(2)] …  │ │   ┌──────────────────────────────────────┐ │
│  ┌──────────────┐            │ │   │   10:00   ← 滚轮数字（未位移）        │ │
│  │ 吸气长音  ★  │            │ │   │   ├─┼─┼─┼─┼─┼─┼─┤  刻度尺 60 格        │ │
│  ├──────────────┤            │ │   │  [−]            [+]                 │ │
│  │ 单吐 tuku    │            │ │   │   [ 开始练习 ]  48px 珊瑚红 整宽      │ │
│  ├──────────────┤            │ │   └──────────────────────────────────────┘ │
│  │ 已归档 (37)▾ │            │ │ 3 老师要求卡（与仪表卡同宽，在下方）       │
│  └──────────────┘            │ │   ┌──────────────────────────────────────┐ │
│ 4 速度 + 练什么（可编辑）     │ │   │ 本周老师要求        [示范视频]        │ │
│  ♩=80  [♩][♪][♬]  [− 80 +]   │ │   │ 1. …  2. …  3. …                     │ │
│  [长音][吐音][连吐][+3]      │ │   │ 正文 16px 行高 1.6，结构化排版        │ │
│  [ 练什么? ________________ ] │ │   └──────────────────────────────────────┘ │
└──────────────────────────────┘ └────────────────────────────────────────────┘
   高度预算：顶 44 + 主区 668（左列：科目 300 + 速度内容 200 + 间隙；右列：仪表卡 300 + 要求卡 340 + 间隙 28）
```

**取舍说明**
- 「选什么」放左列（科目在上、速度/session 在下，都是"决定"）；「练多久 + 开始 + 要求」放右列（仪表卡与要求卡上下同宽，符合 dad 的要求）
- 仪表卡与要求卡同宽同列 → 进入练习态时**位置不跳**，只换内容状态（平滑过渡的关键）
- 科目区固定高度、内部滚动；归档分组折叠在最后

## 3. 练习态布局草案

目标：**围绕一个完整的中央仪表盘**，一屏之内完成"练 + 看要求"。

```
┌ 顶部条 44px ─────────────────────────────────────────────────────────────────┐
│ 练习打卡    进行中 · 已练 03:12 · 还剩 06:48                     [今日记录 ▾] │
└──────────────────────────────────────────────────────────────────────────────┘
┌ 中央仪表盘（全宽 1037 或居中 900）────────────────────────────────────────────┐
│  ┌───────────────────────────────┬────────────────────────────────────────┐  │
│  │ 左：身份（只读）              │ 中：时间（核心）                        │  │
│  │  吸气长音                     │       03:12  ← 72px 滚轮数字           │  │
│  │  ♩=80  长音练习               │   ├─┼─┼─┼─┼─┼─┼┤  进度刻度尺 + 花朵    │  │
│  │  （BPM 与 session 小字）      │                                        │  │
│  │                               │   [暂停]  [提前结束]                    │  │
│  └───────────────────────────────┴────────────────────────────────────────┘  │
└──────────────────────────────────────────────────────────────────────────────┘
┌ 老师要求卡（与仪表盘同宽，正文 16-18px，结构化）──────────────────────────────┐
│ 1. …（边练边看）  2. …  3. …                                        ┌────────┐ │
│                                                                     │ 今日记录│ │
│                                                                     │ 折叠条 │ │
└─────────────────────────────────────────────────────────────────────┴────────┴─┘
   高度预算：顶 44 + 仪表盘 400 + 要求卡 250 + 底部条 44 + 间隙 16 ≈ 754（略超 744 → 需要压 10-20px，见候选）
```

**练习态三个候选（供与 agy 对照）**

- **R1 上下式（贴合 dad 的要求）**：仪表盘在上（400）→ 要求卡在下（260）→ 今日记录做成右侧 200px 竖条与要求卡并排。总高 44+400+260+16 ≈ 720 ✓
- **R2 左侧记录栏**：左侧 260px 竖栏 = 今日记录（滚动），右侧 = 仪表盘 + 要求卡。会牺牲"要求卡与仪表盘同宽"的宽度
- **R3 要求卡与仪表盘融合**：仪表盘下半部分留出"要求摘要 2 行"，全文仍在下方卡（默认展示）

**练习态必须回答的细节**
1. 仪表盘里"身份（科目 + BPM + session）"放左、中、右还是横排小字？只读态如何弱化但保持可读？
2. 暂停态与运行态的差别（读数变化 / 胶囊文案 / CTA 文案：暂停 ↔ 继续）
3. 提前结束是"第二权重"CTA，位置与尺寸要给规范
4. 花朵/卷草纹生长动画在主视觉里的层级（不能压过读数）
