## What learned (额外 4 条)
1. **A3 横向 ISO 420×297mm 是 iPad mini 看 7 天的 sweet spot** — A4 横向 297mm 物理装不下, A3 打印支持 (虽然默认 A4 打印机不会印 A3 留白)
2. **`urlretrieve` 缺 retry + timeout** — 现代 CDN (FAL / Cloudflare R2) 偶发 SSL EOF, 必用 `urlopen` + 显式 SSL context + chunk 8KB 流式
3. **CSS `text-align: center` 继承链不稳** — 加 `!important` 显式声明防其他规则覆盖, 8mm 窄列 + nowrap 文字特别敏感
4. **测试隔离铁律 v2** — TDD 抽 `_download_image_with_retry` 纯函数 + `extract_image_source` 纯函数, mock urllib 而不 mock 整个 subprocess, pytest 0.19s 跑 31 个新 test, 没污染 cli_ux_review 等其他 test
