## Sprint 回顾

- **What shipped (5)**:
  1. iPad mini 横屏适配 (矩阵 8pt→11pt, 取消死宽, 短列 min-width 保底, 分组视图同步放大)
  2. 表格视图屏上可滚动 + 打印可多页 (取消 210mm height 限制; 打印 thead 重复 + break-inside avoid)
  3. 图片导出产出物 (工具条按钮 + POST /api/practices/stage-image SSE + report_artifacts 表)
  4. A3 横向 420x297mm 装 7 天 (dad 视觉反馈: 6 天表格 A4 装不下, 改 A3)
  5. CDN 下载 retry 3 次 + 显式 SSL context (dad 实战 SSL EOF bug 修)
- **What learned (4)**:
  1. **测试隔离铁律** — 任何 monkeypatch 共享状态 (db, settings, sys.modules) 必须用 pytest fixture, 不能手动 setattr 后不还原
  2. **A3 横向 ISO 420×297mm 是 iPad mini 看 7 天的 sweet spot** — A4 横向 297mm 物理装不下, A3 打印支持
  3. **TDD 抽纯函数 + monkeypatch fixture 让净 0 回归可期** — 抽 extract_image_source + _download_image_with_retry 到独立模块, mock urllib 而不 mock subprocess, 0.19s 跑 31 个新 test 不污染 cli_ux_review
  4. **`urlretrieve` 缺 retry + timeout** — 现代 CDN 偶发 SSL EOF, 必用 `urlopen` + 显式 SSL context + chunk 8KB 流式
